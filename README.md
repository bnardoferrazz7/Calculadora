Projeto desenvolvido como atividade prática do curso técnico de Analista de Dados da EBAC, utilizando Python e Linux.

O projeto contém uma calculadora desenvolvida originalmente em Python e um script executável em Bash para ambiente Linux.

1. Código Python (calculadora.py)

A calculadora foi desenvolvida utilizando Python e permite realizar quatro operações matemáticas:

Soma;

Subtração;

Multiplicação;

Divisão.

O código utiliza:

input() para receber os números e a operação escolhida.

float() para converter os valores em números decimais.

if, elif e else para selecionar a operação.

while para permitir repetir os cálculos.

Verificação para evitar divisão por zero.

2. Script Linux (calculadora.sh)

O arquivo calculadora.sh contém a versão da calculadora desenvolvida em Shell Script (Bash), permitindo sua execução diretamente pelo terminal Linux.

Como executar:

Abra o terminal Linux na pasta onde está o arquivo.

Configure a permissão de execução:

chmod 744 calculadora.sh

Execute o programa:

./calculadora.sh
